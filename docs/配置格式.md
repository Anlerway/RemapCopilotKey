# 配置文件格式

配置文件名为 `config.json`，放在**程序目录**（服务程序与配置程序所在的那个目录），
编码为 **UTF-8 无 BOM**。

服务程序每 2 秒检查一次文件的时间戳与大小，发现变化就立刻重新加载，
所以改完**直接保存即可生效**，不需要重启（前提是 `mapping.reloadOnChange` 为 `true`）。

> 手改配置文件出错不会让服务起不来：非法的单项会回退成默认值，
> 同时在日志里记一条警告。

---

## 完整结构

```json
{
  "version": 1,
  "language": "zh-CN",
  "logLevel": "info",
  "enabled": true,

  "mapping": {
    "trigger": "copilotKey",
    "reloadOnChange": true,
    "action": {
      "type": "sendKey",
      "vkey": "VK_RCONTROL"
    }
  }
}
```

## 字段说明

### 顶层

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `version` | 整数 | `1` | 配置格式版本。目前只有 1。 |
| `language` | 字符串 | `"zh-CN"` | 界面语言，对应 `src/Configurator/Lang/` 下的语言包代码。影响配置程序界面与服务程序对话框。 |
| `logLevel` | 字符串 | `"info"` | 日志级别：`off` / `error` / `warn` / `info` / `debug`。排查问题时改成 `debug`。 |
| `enabled` | 布尔 | `true` | 总开关。为 `false` 时键盘钩子仍然安装，但不拦截任何按键。 |


### `mapping`

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `trigger` | 字符串 | `"copilotKey"` | 触发方式。目前只支持 `copilotKey`（即 `左Win + 左Shift + F23` 序列）。其它值会被回退成 `copilotKey` 并记警告。 |
| `reloadOnChange` | 布尔 | `true` | 配置文件变化时是否自动重新加载。 |
| `action` | 对象 | 见下文 | 触发时执行的动作。 |

---

## `mapping.action` 的五种写法

### 1. 映射为按键（`sendKey`）

按住 Copilot 键时目标按键保持按下，松开时一起松开。这是默认动作。

```json
{ "type": "sendKey", "vkey": "VK_RCONTROL" }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `vkey` | 字符串 | 是 | 目标按键名。写错会回退成 `VK_RCONTROL`。 |

> **为什么默认是右 Ctrl**：微软要求没有多余键位的键盘用 Copilot 键替换右 Ctrl，
> 这个动作就是把右 Ctrl 还回去。选 `VK_CONTROL`（通用 Ctrl）也可以，
> 系统会自行解析成左右 Ctrl。

### 2. 映射为组合键（`sendChord`）

按一下 Copilot 键，就发送一次完整组合键（依次按下，再逆序松开）。

```json
{ "type": "sendChord", "keys": ["VK_CONTROL", "VK_SHIFT", "VK_ESCAPE"] }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keys` | 字符串数组 | 是 | 按下顺序排列的按键名。空数组会回退成 `Ctrl+Shift+Esc`。数组里无法识别的项会被忽略并记警告。 |

> 配置程序里这一项是**输入捕获**式的：点一下输入框，然后直接按键盘即可录制，
> **最多三个键**（例如 `Ctrl + Shift + Esc`）。
> 注意 Windows 键会被操作系统抢先处理，普通窗口捕获不到；需要 Win 组合请直接用
> 下面的 `systemAction` 预置项，或手工在配置文件里写 `VK_LWIN`。

### 3. 打开应用程序（`openApp`）

```json
{ "type": "openApp", "path": "C:\\Windows\\System32\\notepad.exe", "args": "" }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | 字符串 | 是 | 可执行文件路径，也可以是任何能被 `ShellExecute` 打开的东西（文档、文件夹）。JSON 里反斜杠要写成 `\\`。 |
| `args` | 字符串 | 否 | 命令行参数。 |
| `runAsAdmin` | 布尔 | `false` | 被打开的程序是否以管理员权限运行（ShellExecute 的 runas 动词）。 |
| `toggleWindow` | 布尔 | `false` | 为 `true` 时，如果该程序**已经在运行**，再次触发只会最小化/还原它的窗口，而不是再启动一个实例。 |

### 4. 打开网页（`openUrl`）

```json
{ "type": "openUrl", "url": "https://github.com/" }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `url` | 字符串 | 是 | 交给系统默认浏览器打开。 |

### 5. Windows 实用功能（`systemAction`）

```json
{ "type": "systemAction", "action": "taskManager" }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `action` | 字符串 | 是 | 见下表。无法识别会回退成 `explorer`。 |

> **再次按下会关闭**：对于会启动程序的实用功能（资源管理器 / 任务管理器 / cmd /
> PowerShell / 计算器 / 记事本 / 控制面板），如果该程序已经在运行，再次触发会
> **关闭它**（发送 `WM_CLOSE`）；没在运行才启动。发送快捷键的那些
> （截图 / 任务视图 / 剪贴板历史 / 表情面板 / 锁定屏幕）不受影响。

| `action` | 行为 | 中文界面显示 |
|---|---|---|
| `explorer` | 启动 `explorer.exe` | 文件资源管理器 |
| `taskManager` | 启动 `taskmgr.exe` | 任务管理器 |
| `cmd` | 启动 `cmd.exe` | 命令提示符 |
| `powershell` | 启动 `powershell.exe` | PowerShell |
| `screenshot` | 发送 `Win+Shift+S` | 截图 |
| `snippingTool` | 打开 `ms-screenclip:` | 截图工具 |
| `settings` | 打开 `ms-settings:` | 设置 |
| `controlPanel` | 启动 `control.exe` | 控制面板 |
| `calculator` | 启动 `calc.exe` | 计算器 |
| `notepad` | 启动 `notepad.exe` | 记事本 |
| `taskView` | 发送 `Win+Tab` | 任务视图 |
| `clipboardHistory` | 发送 `Win+V` | 剪贴板历史 |
| `emojiPanel` | 发送 `Win+.` | 表情符号面板 |
| `lockScreen` | 发送 `Win+L` | 锁定屏幕 |

## 按键名清单

按键名以 `VK_` 开头。解析时**大小写不敏感**，可以省略 `VK_` 前缀，
也支持一批常用别名。

**别名**：`CTRL` `CONTROL` → `VK_CONTROL`；`SHIFT` → `VK_SHIFT`；`ALT` `MENU` → `VK_MENU`；
`RCTRL` `RCONTROL` → `VK_RCONTROL`；`WIN` `LWIN` → `VK_LWIN`；
`ENTER` `RETURN` → `VK_RETURN`；`ESC` → `VK_ESCAPE`；`DEL` → `VK_DELETE`；`INS` → `VK_INSERT`；
`BACKSPACE` → `VK_BACK`；`PAGEUP` → `VK_PRIOR`；`PAGEDOWN` → `VK_NEXT`；
`PRTSC` `PRINTSCREEN` → `VK_SNAPSHOT`。

> 注意：`CTRL` / `SHIFT` / `ALT` 指向**通用**修饰键（`VK_CONTROL` / `VK_SHIFT` / `VK_MENU`），
> 不是右 Ctrl / 右 Shift。要明确指定左右请写 `VK_RCONTROL` / `VK_RSHIFT`。

## 示例

### 还原右 Ctrl（默认）

```json
{
  "version": 1,
  "language": "zh-CN",
  "logLevel": "info",
  "enabled": true,
  "mapping": {
    "trigger": "copilotKey",
    "reloadOnChange": true,
    "action": { "type": "sendKey", "vkey": "VK_RCONTROL" }
  }
}
```

### 当"任务管理器"快捷键用

```json
{ "type": "sendChord", "keys": ["VK_CONTROL", "VK_SHIFT", "VK_ESCAPE"] }
```

### 当"截图"键用

```json
{ "type": "systemAction", "action": "screenshot" }
```

### 当"打开终端"用

```json
{ "type": "systemAction", "action": "powershell" }
```

### 打开常用文件夹

```json
{ "type": "openApp", "path": "D:\\Projects", "args": "" }
```

## 命令行参数（服务程序）

| 参数 | 说明 |
|---|---|
| （无） / `--run` | 启动服务（**后台静默运行，无托盘、无界面**） |
| `--stop` | 停止正在运行的实例。已停止返回 2 |
| `--config <路径>` | 使用指定的配置文件（默认：程序目录\config.json） |
| `--loglevel <级别>` | 临时覆盖日志级别：off / error / warn / info / debug |
| `--quiet` | 不弹出任何对话框 |
| `--help` | 显示用法 |

> 早期版本还有 `--install` / `--uninstall` / `--status`。
> 开机自启（计划任务）的注册与删除现在由**配置程序**负责
> （见 `src/Configurator/AutoStart.cs`，用的是计划任务的 COM 接口），
> 服务程序侧已移除这三个参数。
>
> ⚠️ **这条自启路径目前不可用**：计划任务拉起的实例是低完整性(0x1000)、
> 键盘钩子收不到按键。详见 `docs/设计说明.md` 第 8.2 节。

## 命令行参数（配置程序）

| 参数 | 说明 |
|---|---|
| （无） | 打开图形界面 |
| `--dump-default-config <路径>` | 写出一份默认配置后退出（不开窗口），用于校验 JSON 契约 |
| `--export-task <路径>` | 导出**系统里已注册**的计划任务定义（UTF-8，并列出 LogonType / RunLevel / UserId / GroupId / 动作）后退出 |
| `--diagnose` | 把启动过程中的每一步写进 `%TEMP%\RemapCopilotKey.Configurator.log` |
